# Supported Environments

## Supported JVM

- Java 25 (minimum required to build and run KADAI)

Selected KADAI modules are also tested with Java 27 in CI.

## Supported Databases

You can choose one of the following databases:

- DB2 11.5
- PostgresSQL 17

## Container/Application Server (optional)

- Embedded Tomcat of Spring Boot

## Web Browser (optional)

- Google Chrome (latest 2 versions)
- Mozilla Firefox (latest 2 versions)
- Microsoft Edge (latest 2 versions)
